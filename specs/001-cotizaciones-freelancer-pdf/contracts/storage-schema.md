# [Obsoleto] Esquema de Almacenamiento Local

Este contrato describía el esquema de `localStorage` de la versión sin backend de la
aplicación (constitución v1.0.0). Quedó reemplazado el 2026-09-07 al adoptar Angular +
Java/Spring Boot como arquitectura estándar del proyecto (constitución v2.0.0): los
datos ahora se persisten en la base de datos del backend.

Ver [data-model.md](../data-model.md) para las entidades actuales y
[api-rest.md](./api-rest.md) para cómo el frontend accede a ellas.
